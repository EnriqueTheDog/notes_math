
Una operación interna es una [[aplicación]] de $E·E$ en $E$.

Es decir, una ley que asocia a todo par $(a, b)$ de elementos de $E$ un elemento único de $E$, denotado$$a\star b$$
## elemento neutro

Se llama elemento neutro de una operación interna a aquel $$e\in E, \forall a\in E (a\star e= e\star a = a)$$
Sería el 0 de la suma o el 1 del producto.
Si existe un elemento neutro para una operación interna, este es único.
## elemento simétrico

Se llama elemento simétrico de un elemento $a\in E$ a aquel$$a'\in E, a\star a' = a'\star a = e$$
Siendo $\star$ una operación interna [[asociación|asociativa]] en $E$ con [[#elemento neutro]] $e\in E$.
Si $a\in E$ tiene elemento neutro, este es único.
